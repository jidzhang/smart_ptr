========================================
smart_ptr.h 修改总结
========================================

主要修改
--------
1. 修复了 release() 函数中潜在的 use-after-free 问题
   - 在删除 m_counter 前保存判断条件
   - 确保 m_ptr 在所有情况下都被正确清空

2. 添加了 Safe Bool Idiom
   - 替换危险的 operator T*() 隐式转换
   - 防止意外的类型转换（如 int x = sp;）

3. 移除了 unique_ptr 的 virtual 析构函数
   - 减少虚函数表开销
   - unique_ptr 不需要多态

4. 修复了命名空间结束符的分号问题
   - 从 }; 改为 }
